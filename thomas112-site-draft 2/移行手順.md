# Thomas株式会社 Webサイト更新メモ

このフォルダーは、GitHub Pagesで公開中のThomas株式会社サイトを更新するための静的HTML一式です。Jimdoはすでに解約済みと伺っています。今回の作業では、GitHub・GitHub Pages・DNS・Xserverの設定変更や公開操作はしていません。

## ファイル構成

- `index.html` — トップページ
- `事業内容/` — 4事業の紹介
- `会社概要/` — 理念、経営姿勢、会社情報、沿革
- `お問い合わせ/` — 電話とGoogleフォーム
- `概要/` — 運営者情報
- `プライバシーポリシー/` — 公開前の内容確認が必要
- `style.css`、`site.js`、`images/` — 共通デザイン、動き、画像

ページからCSS・画像・他ページへのリンクは相対パスです。サイト公開フォルダー直下に `index.html` と `style.css` が並ぶ構成を保ってください。

## 既存のGitHub Pagesへ反映する場合

1. 既存リポジトリの現在のファイル一式を手元にバックアップします。
2. このフォルダー内のWebサイト用ファイルを、リポジトリの公開元フォルダーへ反映します。
3. 既存リポジトリに `CNAME`、`404.html`、`.nojekyll` などがある場合は、用途を確認せず削除・上書きしないでください。独自ドメインの設定を保つため、既存の `CNAME` は特に維持してください。
4. 変更をコミット・プッシュし、GitHubのリポジトリ画面でPagesのビルドが完了したことを確認します。
5. 公開URLをPCとスマートフォンで開き、各ページ、画像、電話リンク、Googleフォームを確認します。

このメモは更新時の確認用です。GitHub Pagesの公開元やドメイン設定は変更していません。Xserverのメールを継続するため、DNSのMX・SPF等のメール用レコードも変更しないでください。

## 公開前に確認すること

- 会社情報、電話番号、許可・登録情報が最新であること
- プライバシーポリシーが、Googleフォームを含む現在の個人情報の取得・利用方法に合っていること
- Googleフォームが社外から回答可能で、通知・回答保存の設定が希望どおりであること
- 画像は説明用のイメージです。実際の現場・社員・施工実績として紹介しないでください。サイト上のAI生成注記は依頼者の希望により掲載していません。
